# Agentes de Heimdall

- Al empezar, lee [CLAUDE.md](CLAUDE.md) y el estado actual en
  [docs/project/PROGRESS.md](docs/project/PROGRESS.md).
- Para elegir trabajo, ejecuta `python3 scripts/tasks.py`; para sus criterios
  completos, `python3 scripts/tasks.py T165` (sustituye el ID por el elegido).
- Para localizar código y pruebas, consulta
  [las entradas por trabajo](docs/DESARROLLO.md#entradas-por-trabajo).
- Para revisar un intervalo o preparar el relevo, consulta
  [el flujo entre sesiones](docs/project/AGENT-WORKFLOW.md).
